发布npm包完整指南

📋 准备工作

  1. 注册npm账号 - npm官网 注册
  2. 安装nrm - npm install -g nrm （管理npm源）
  3. 源码跟打包后的包分离 - dist => npm; src => github
  4. 准备Git仓库 - GitHub/GitLab等代码托管平台
  5. 测试验证功能 - jest
  6. 打包工具 - 一般这种功能包用rollup

🚀 完整发布流程

1. 创建项目并关联Git

2. 初始化npm包

3. 配置package.json

4. 创建源代码

5. 配置构建工具

rollup.config.mjs

6. 切换npm源

7. 登录npm

8. 检查包名

9. 构建并发布

10. 验证发布

1. 修改代码

2. 提交到Git

3. 更新版本号

4. 重新发布

⚠️ 关键要点

  1. 源码管理 - 源代码放在Git仓库，npm只发布构建产物
  2. 构建分离 - 使用构建工具生成dist目录
  3. 文件控制 - 通过files字段和.npmignore控制发布内容
  4. 版本同步 - Git提交和npm发布保持同步
  5. 包名唯一 - 确保包名在npm上唯一

📝 发布检查清单

  • Git仓库已创建并关联
  • 源代码已编写
  • package.json已配置
  • 构建配置已完成
  • 包名已检查
  • 已登录npm
  • 已构建项目
  • 已发布包
  • 已验证发布成功
