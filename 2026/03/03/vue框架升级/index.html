vue框架升级 - 大型项目的平滑迁移

OHNII2026年03月03日2026年03月31日

项目架构升级实战指南 (Vue 2 -> Vue 3 / Webpack -> Vite)

本手册记录了 eco-etc-firm-fleet-ui-v3 从旧版技术栈全面升级至现代前端基座的完整路径、核心脚本与具体操作流程。

1. 架构设计全景对比 (Framework Comparison)

维度 Webpack 旧架构 (Legacy) Vite + Vue 3 新架构 (Current) 升级理由
Node.js v14.x v24.x 长期支持版，性能更强
包管理器 npm pnpm 节省磁盘空间，安装飞快
构建工具 Webpack 4 / Vue CLI Vite 7.3 毫秒级热更新，开发体验质变
前端框架 Vue 2.7.16 Vue 3.x 组合式 API，更好的 TS 支持
UI 组件库 element-ui 2.13 element-plus 适配 Vue 3，更现代的 UI
状态管理 Vuex 3.x Pinia 2.x 类型安全，逻辑更扁平
路由库 vue-router 3.x vue-router 4.x 适配 Vue 3，API 更简洁
Sass 引擎 node-sass (经常安装失败) sass (Dart Sass) 无需编译二进制，跨平台稳定

2. 核心迁移流水线 (Step-by-Step)

Step 1: 环境与依赖重置

  1. 清理旧环境: 删除 node_modules 和 package-lock.json。
  2. 引擎升级: 在 package.json 中设置 "engines": { "node": ">=24" }。
  3. 核心包替换:

Step 2: 自动化脚本修复 (关键操作)

为了批量处理数千个文件，我们编写并执行了以下 Node.js 脚本：

脚本名称 具体作用 操作流程
fix-styles.js 将 /deep/ 替换为 ::v-deep node fix-styles.js
remove-tilde.js 移除 CSS 中废弃的 ~@/ 前缀 node remove-tilde.js
rename-variables.js 将 variables.scss 转为 .module.scss node rename-variables.js
migrate-imports.js 将 @vue/composition-api 引用改为 vue node migrate-imports.js

Step 3: 构建引擎切换 (Vite 配置)

  1. 移动 HTML: 将 public/index.html 移至根目录，添加 <script type="module" src="/src/main.js"></script>。
  2. 配置别名: 在 vite.config.js 中配置 @ 和 path 的映射。
  3. 注入全局变量: 使用 define 模拟 process.env.NODE_ENV 以兼容旧代码。
  4. Require 处理: 使用 vite-plugin-require-transform 拦截并转换 .vue 中的图片 require。

Step 4: 框架代码重写

  1. 入口重构: 将 main.js 从 new Vue() 模式重写为 createApp() 模式。
  2. Pinia 桥接: 创建 src/store/pinia-shim.js，通过全局属性 $store 模拟 Vuex 的 dispatch/commit 接口，实现旧组件无感知迁移。
  3. 路由升级: 将 router.js 升级至 Router 4 规范，通配符 * 改为 :pathMatch(.*)*。

4. 后续路线图 (Roadmap)

  1. ** Step 3: 业务适配 (进行中) **
    • Filters: 将 {{ time | formatDate }} 改为 formatDate(time)。
    • v-model: 组件通信修改（value -> modelValue, sync -> v-model:xxx）。
  2. ** Step 4: UI 对齐 (待开始) **
    • Element Plus: 检查 size="medium" 等失效属性，对齐为 default/large/small。
  3. ** Step 5: 性能优化 **
    • Manual Chunks: 在 Vite 中配置 Rollup 拆包，减少首屏体积。

5.2 移除波浪号脚本 (remove-tilde.js)

作用：移除 Vite 不再需要的 @import "~@/..." 前缀。

5.3 变量重命名脚本 (rename-variables.js)

作用：重命名 variables.scss 并在项目中更新所有引用路径。

5.4 导入路径迁移脚本 (migrate-imports.js)

作用：将 @vue/composition-api 统一重写为原生的 vue 导入。
